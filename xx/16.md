可以，这次我按“**完全从零开始，最后得到一个真的能运行的 YAgent Runtime**”来写，不只是目录说明，而是把你第一版需要的代码、文件、启动方式、测试方式都落下来。

为了避免你一下子被 MCP、Sandbox、Tool Calling 绕晕，我们做的是一个“完整但分阶段”的版本。最终结构会包含你列出来的这些模块，而且第一版能真正做到：

```text
用户请求
  ↓
RuntimeController
  ↓
AgentService
  ↓
AgentRuntime
  ↓
SessionManager
  ↓
DeepSeek
  ↓
如果模型需要工具
  ↓
ToolManager
  ↓
ToolInvoker
  ↓
本地 Tool / MCP Tool
  ↓
把结果再次交给 DeepSeek
  ↓
返回最终回答
```

现在 DeepSeek 官方 OpenAI 兼容接口的 `base_url` 是 `https://api.deepseek.com`，当前官方文档列出的模型包括 `deepseek-v4-flash` 和 `deepseek-v4-pro`，并支持 Tool Calls。([Deepseek API Docs][1])

MCP 这边现在 TypeScript SDK 已经进入 v2，客户端包拆成了 `@modelcontextprotocol/client`；本地 MCP 使用 `StdioClientTransport`。([MCP TypeScript SDK][2])

# 十、写 SessionManager

创建：

```text
src/session/SessionManager.ts
```

内容：

```typescript
import {
    SessionContext,
    SessionMessage
} from './SessionContext.js';


export class SessionManager {

    private readonly sessions =
        new Map<string, SessionContext>();


    getOrCreate(
        sessionId: string
    ): SessionContext {

        let session =
            this.sessions.get(sessionId);


        if (!session) {

            const now = Date.now();


            session = {

                sessionId,

                createdAt: now,

                updatedAt: now,

                messages: []
            };


            this.sessions.set(
                sessionId,
                session
            );
        }


        return session;
    }


    get(
        sessionId: string
    ): SessionContext | undefined {

        return this.sessions.get(sessionId);
    }


    addMessage(
        sessionId: string,
        message: SessionMessage
    ): void {

        const session =
            this.getOrCreate(sessionId);


        session.messages.push(message);

        session.updatedAt =
            Date.now();
    }


    clear(
        sessionId: string
    ): void {

        this.sessions.delete(sessionId);
    }


    list(): SessionContext[] {

        return [
            ...this.sessions.values()
        ];
    }
}
```

# 十二、创建 DeepSeekClient

创建：

```text
src/adapter/deepseek/DeepSeekClient.ts
```

写：

```typescript
import OpenAI from 'openai';

import {
    ChatCompletionMessageParam,
    ChatCompletionTool
} from 'openai/resources/chat/completions';

import {
    DeepSeekAssistantResult
} from './DeepSeekTypes.js';


export class DeepSeekClient {

    private readonly client: OpenAI;

    private readonly model: string;


    constructor() {

        const apiKey =
            process.env.DEEPSEEK_API_KEY;


        if (!apiKey) {

            throw new Error(
                '缺少环境变量 DEEPSEEK_API_KEY'
            );
        }


        this.client =
            new OpenAI({

                apiKey,

                baseURL:
                    process.env.DEEPSEEK_BASE_URL
                    ?? 'https://api.deepseek.com'
            });


        this.model =
            process.env.DEEPSEEK_MODEL
            ?? 'deepseek-v4-flash';
    }


    async chat(
        messages: ChatCompletionMessageParam[],
        tools?: ChatCompletionTool[]
    ): Promise<DeepSeekAssistantResult> {

        const response =
            await this.client.chat.completions.create({

                model: this.model,

                messages,

                tools:
                    tools && tools.length > 0
                        ? tools
                        : undefined,

                tool_choice:
                    tools && tools.length > 0
                        ? 'auto'
                        : undefined
            });


        const message =
            response.choices[0]?.message;


        if (!message) {

            throw new Error(
                'DeepSeek没有返回有效消息'
            );
        }


        return {

            content:
                message.content ?? null,

            toolCalls:
                message.tool_calls?.map(
                    item => ({

                        id: item.id,

                        type: 'function',

                        function: {

                            name:
                                item.function.name,

                            arguments:
                                item.function.arguments
                        }
                    })
                ) ?? []
        };
    }
}
```

这里最重要的是：

```typescript
new OpenAI({
    apiKey,
    baseURL: 'https://api.deepseek.com'
})
```

因为 DeepSeek 官方提供 OpenAI 兼容调用方式。([Deepseek API Docs][1])

import {
    ChatCompletionTool
} from 'openai/resources/chat/completions';

import {
    ToolRegistry
} from './ToolRegistry.js';

import {
    ToolInvoker
} from './ToolInvoker.js';


export class ToolManager {

    constructor(
        private readonly registry:
            ToolRegistry,

        private readonly invoker:
            ToolInvoker
    ) {
    }


    getLlmTools():
        ChatCompletionTool[] {

        return this.registry
            .list()
            .map(tool => ({

                type: 'function',

                function: {

                    name:
                        tool.definition.name,

                    description:
                        tool.definition.description,

                    parameters:
                        tool.definition.inputSchema
                }
            }));
    }


    async invoke(
        name: string,
        argumentText: string
    ): Promise<unknown> {

        let args:
            Record<string, unknown>;


        try {

            args =
                argumentText
                    ? JSON.parse(
                        argumentText
                    )
                    : {};

        } catch {

            throw new Error(
                `工具参数不是合法JSON: ${argumentText}`
            );
        }


        return await this.invoker.invoke(
            name,
            args
        );
    }
}

# 二十六、MCP Client

创建：

```text

```

第一版先做本地 stdio MCP。

当前 MCP TypeScript v2 客户端使用：

```typescript
Client
StdioClientTransport
```

官方文档也是这个调用模型。([MCP TypeScript SDK][3])

写：

```typescript
import {
    Client
} from '@modelcontextprotocol/client';

import {
    StdioClientTransport
} from '@modelcontextprotocol/client/stdio';


export interface McpServerConfig {

    name: string;

    command: string;

    args: string[];
}


export class McpClient {

    private readonly clients =
        new Map<string, Client>();


    async connect(
        config: McpServerConfig
    ): Promise<void> {

        if (
            this.clients.has(
                config.name
            )
        ) {

            return;
        }


        const client =
            new Client({

                name:
                    'yagent-runtime',

                version:
                    '0.0.1'
            });


        const transport =
            new StdioClientTransport({

                command:
                    config.command,

                args:
                    config.args
            });


        await client.connect(
            transport
        );


        this.clients.set(
            config.name,
            client
        );
    }


    async listTools(
        serverName: string
    ) {

        const client =
            this.clients.get(
                serverName
            );


        if (!client) {

            throw new Error(
                `MCP服务器未连接: ${serverName}`
            );
        }


        const result =
            await client.listTools();


        return result.tools;
    }


    async callTool(
        serverName: string,
        toolName: string,
        args:
            Record<string, unknown>
    ) {

        const client =
            this.clients.get(
                serverName
            );


        if (!client) {

            throw new Error(
                `MCP服务器未连接: ${serverName}`
            );
        }


        return await client.callTool({

            name:
                toolName,

            arguments:
                args
        });
    }


    async closeAll():
        Promise<void> {

        for (
            const client
            of this.clients.values()
        ) {

            await client.close();
        }


        this.clients.clear();
    }
}
```

MCP 的流程就是：

```text
connect
 ↓
listTools
 ↓
callTool
```

# 二十七、真正实现 AgentRuntime

这是整个项目最重要的文件。

创建：

```text
src/agent/AgentRuntime.ts
```

写：

```typescript
import {
    ChatCompletionMessageParam
} from 'openai/resources/chat/completions';

import {
    SessionManager
} from '../session/SessionManager.js';

import {
    DeepSeekClient
} from '../adapter/deepseek/DeepSeekClient.js';

import {
    ToolManager
} from '../tool/ToolManager.js';

import {
    PermissionClient
} from '../permission/PermissionClient.js';


export class AgentRuntime {

    private static readonly
    MAX_TOOL_ROUNDS = 8;


    constructor(

        private readonly sessionManager:
            SessionManager,

        private readonly deepSeekClient:
            DeepSeekClient,

        private readonly toolManager:
            ToolManager,

        private readonly permissionClient:
            PermissionClient
    ) {
    }


    async run(
        sessionId: string,
        userMessage: string
    ): Promise<string> {

        /**
         * 1.
         * 获取 Session
         */
        const session =
            this.sessionManager
                .getOrCreate(
                    sessionId
                );


        /**
         * 2.
         * 保存用户消息
         */
        this.sessionManager.addMessage(
            sessionId,
            {

                role:
                    'user',

                content:
                    userMessage
            }
        );


        /**
         * 3.
         * 构造模型上下文
         */
        const messages:
            ChatCompletionMessageParam[] = [

                {

                    role:
                        'system',

                    content:
                        `
你是 YAgent Runtime 中运行的智能 Agent。

你的目标：
1. 理解用户需求。
2. 如果有工具可以完成任务，应合理调用工具。
3. 工具执行结果必须作为事实依据。
4. 不要编造工具执行结果。
5. 如果不需要工具，直接回答。
                        `.trim()
                }
            ];


        for (
            const item
            of session.messages
        ) {

            if (
                item.role === 'user'
            ) {

                messages.push({

                    role:
                        'user',

                    content:
                        item.content
                });
            }


            if (
                item.role ===
                'assistant'
            ) {

                messages.push({

                    role:
                        'assistant',

                    content:
                        item.content
                });
            }
        }


        /**
         * 4.
         * 获取当前能够给模型使用的工具
         */
        const tools =
            this.toolManager
                .getLlmTools();


        /**
         * 5.
         * Agent Loop
         */
        for (
            let round = 0;
            round <
                AgentRuntime.MAX_TOOL_ROUNDS;
            round++
        ) {

            const result =
                await this.deepSeekClient.chat(

                    messages,

                    tools
                );


            /**
             * 模型没有请求工具。
             *
             * 说明已经可以产生最终答案。
             */
            if (
                result.toolCalls.length === 0
            ) {

                const content =
                    result.content
                    ?? '';


                this.sessionManager
                    .addMessage(
                        sessionId,
                        {

                            role:
                                'assistant',

                            content
                        }
                    );


                return content;
            }


            /**
             * 把 assistant tool call
             * 写入模型上下文
             */
            messages.push({

                role:
                    'assistant',

                content:
                    result.content,

                tool_calls:
                    result.toolCalls.map(
                        item => ({

                            id:
                                item.id,

                            type:
                                'function',

                            function: {

                                name:
                                    item.function.name,

                                arguments:
                                    item.function.arguments
                            }
                        })
                    )
            });


            /**
             * 逐个执行 Tool
             */
            for (
                const toolCall
                of result.toolCalls
            ) {

                const toolName =
                    toolCall.function.name;


                /**
                 * 权限校验
                 */
                const allowed =
                    await this.permissionClient
                        .canInvokeTool(

                            sessionId,

                            toolName
                        );


                if (!allowed) {

                    messages.push({

                        role:
                            'tool',

                        tool_call_id:
                            toolCall.id,

                        content:
                            JSON.stringify({

                                success:
                                    false,

                                error:
                                    'Permission denied'
                            })
                    });


                    continue;
                }


                try {

                    const output =
                        await this.toolManager
                            .invoke(

                                toolName,

                                toolCall
                                    .function
                                    .arguments
                            );


                    messages.push({

                        role:
                            'tool',

                        tool_call_id:
                            toolCall.id,

                        content:
                            JSON.stringify(
                                output
                            )
                    });

                } catch (
                    error
                ) {

                    messages.push({

                        role:
                            'tool',

                        tool_call_id:
                            toolCall.id,

                        content:
                            JSON.stringify({

                                success:
                                    false,

                                error:
                                    error instanceof Error
                                        ? error.message
                                        : String(error)
                            })
                    });
                }
            }
        }


        throw new Error(
            'Agent工具调用次数超过最大限制'
        );
    }
}
```

这一段就是 Agent 的核心：

```text
请求模型
 ↓
模型要不要Tool？
 ↓
不要
 ↓
直接返回


模型要Tool
 ↓
执行Tool
 ↓
把Tool结果告诉模型
 ↓
再次请求模型
 ↓
继续
```

这就是最基本的 Agent Loop。

    agentService:
        AgentService,

        (
            req,

                service:
                    'yagent-runtime',

        '/chat',

            req,
            res

                    ChatRequestSchema
                        .parse(
                            req.body
                        );


                const reply =
                    await agentService
                        .chat(

                            request.sessionId,

                            request.message
                        );


                res.json({

                    success:
                        true,

                    data: {

                        sessionId:
                            request.sessionId,

                        reply
                    }
                });

            } catch (
                error
            ) {

                console.error(
                    error
                );


                res.status(500)
                    .json({

                        success:
                            false,

                        message:
                            error instanceof Error
                                ? error.message
                                : String(error)
                    });
            }
        }
    );


    router.get(
        '/sessions/:sessionId',

        (
            req,
            res
        ) => {

            const session =
                sessionManager.get(
                    req.params.sessionId
                );


            if (!session) {

                res.status(404)
                    .json({

                        success:
                            false,

                        message:
                            'Session不存在'
                    });


                return;
            }


            res.json({

                success:
                    true,

                data:
                    session
            });
        }
    );


    router.delete(
        '/sessions/:sessionId',

        (
            req,
            res
        ) => {

            sessionManager.clear(
                req.params.sessionId
            );


            res.json({

                success:
                    true
            });
        }
    );


    return router;
}

达到下面 6 项就算成功：

```text
①
pnpm dev
能启动


②
/runtime/health
能访问


③
/runtime/chat
能和DeepSeek对话


④
相同sessionId
能保持上下文


⑤
模型可以调用add_numbers


⑥
Tool执行以后
模型能生成最终回答
```

一旦这 6 个全部完成，你再开始：

```text
MCP
Capability Search
动态Tool
Sandbox
YAgent Platform
```

不然架构很容易越写越乱。

还有一点和你截图里的旧资料要注意：**现在 MCP TypeScript SDK v2 已经把客户端从原来的单包 `@modelcontextprotocol/sdk` 拆成了 `@modelcontextprotocol/client` 等包**，所以你新项目建议直接按 v2 来，不要照旧教程里的 v1 import 写法。([MCP TypeScript SDK][2])

你现在真正应该从 **第一步做到 `/runtime/health` 跑通**，然后再继续写 Session 和 Agent。这样你哪一步报错，我都可以按你当前代码继续往下带，而不是一次面对整个系统。
