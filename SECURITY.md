# Security Policy

## Reporting a Vulnerability

Please do NOT open a public issue for security vulnerabilities.

Report privately via:
- GitHub Security tab → "Report a vulnerability", or
- Email: 你的邮箱

I will acknowledge within 72 hours and provide a fix or mitigation within 14 days for confirmed issues.

## Scope

In-scope: auth bypass, RCE, SQLi, data exposure, dependency vulns.
Out of scope: physical access, social engineering, local DoS.
